Сервис заявок на ремонт

Веб-приложение для учёта заявок на ремонт оборудования в сети из двух торговых точек.

Технологии

- Python 3.14
- Django 6.1
- SQLite
- Pillow

Реализованные возможности

- Вход по телефону и паролю.
- Три роли: сотрудник, управляющий, владелец сети.
- Создание заявок с описанием, срочностью и фотографией.
- Разграничение доступа к заявкам по ролям и торговым точкам.
- Защита от доступа к чужим заявкам через подмену ID.
- Загрузка только изображений допустимых форматов размером до 10 МБ.
- Последовательная смена статусов: новая → в работе → готово.
- Изменение статусов только управляющим.
- Ограничение количества неудачных попыток входа.

Запуск проекта

1. Установить зависимости:

"pip install -r requirements.txt"

2. Выполнить миграции базы данных:

"python manage.py migrate"

3. Создать администратора:

"python manage.py createsuperuser"

4. Запустить приложение:

"python manage.py runserver"

Проверка тестов

"python manage.py test requests_app"

5. Создать демонстрационные точки и пользователей:
   python manage.py seed_demo


   ## Демонстрационные аккаунты

Пароль для всех аккаунтов: demo12345

- Сотрудник точки А: +10000000001
- Управляющий точки А: +10000000002
- Сотрудник точки Б: +10000000003
- Управляющий точки Б: +10000000004
- Владелец сети: +10000000005

Роли

- Сотрудник видит только собственные заявки.
- Управляющий видит заявки своей точки и может менять их статусы.
- Владелец видит заявки всей сети.

Использование ИИ

ИИ использовался как вспомогательный инструмент при разработке, поиске ошибок и подготовке документации. Основные решения проверялись запуском приложения и тестами. В процессе работы исправлялись ошибки, обнаруженные при проверке предложенного ИИ кода.
