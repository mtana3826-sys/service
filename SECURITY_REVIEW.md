Анализ безопасности исходного кода

В ходе анализа исходного кода выявлены следующие уязвимости:

1. Небезопасные настройки

Проблема: SECRET_KEY указан непосредственно в коде, DEBUG=True.

Риск: Утечка секретного ключа и раскрытие служебной информации приложения.

Исправление: Хранить SECRET_KEY в переменных окружения, отключить DEBUG на рабочем сервере.

2. SQL-инъекция

Проблема: SQL-запрос формируется через f-строку с использованием пользовательского ввода.

Риск: Злоумышленник может изменить запрос и получить доступ к данным.

Исправление: Использовать параметризованные запросы или ORM Django.

3. IDOR при получении расчётного листка

Проблема: Не проверяется, принадлежит ли расчётный листок текущему пользователю.

Риск: Пользователь может подменить ID и получить чужие персональные данные.

Исправление: Проверять права доступа и принадлежность документа пользователю на сервере.

4. Mass assignment

Проблема: Все переданные пользователем поля записываются в объект без проверки.

Риск: Можно изменить защищённые данные, например роль или права доступа.

Исправление: Разрешать изменение только заранее определённых полей.

5. Небезопасное хранение паролей

Проблема: Пароль сравнивается напрямую с сохранённым значением.

Риск: При утечке базы данных пароли могут стать доступны злоумышленнику.

Исправление: Использовать стойкое хеширование паролей с солью.

6. Предсказуемый токен

Проблема: Токен формируется на основе ID пользователя.

Риск: Его можно предсказать и использовать для получения доступа к аккаунту.

Исправление: Генерировать криптографически стойкие случайные токены с ограниченным сроком действия.

7. Отсутствие ограничения попыток входа

Проблема: Не ограничено количество неудачных попыток авторизации.

Риск: Возможен подбор пароля методом перебора.

Исправление: Ввести ограничение попыток входа и временную блокировку.

8. Небезопасная загрузка файлов

Проблема: Не проверяются тип, размер и содержимое файла, используется переданное пользователем имя.

Риск: Возможна загрузка вредоносных файлов, переполнение хранилища или перезапись других файлов.

Исправление: Проверять формат и размер файла, генерировать безопасные имена и ограничивать допустимые типы файлов.
